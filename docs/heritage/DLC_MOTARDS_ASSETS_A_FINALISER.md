# GHOSTLINK — Reprise visuelle DLC Motards

## État livré
Le DLC **La Traversée de l'Unité** est intégré au code. Le visuel choisi pour Kino la Foudre est inclus comme `assets/img/boss_kino.jpg`.

Le moteur charge normalement les cartes de boss en `.webp`. Tant que les visuels définitifs ne sont pas ajoutés, le fallback néon affiche les initiales des boss au lieu d'une image cassée.

## Assets à intégrer plus tard
Placez les fichiers dans `assets/img/` avec exactement ces noms :
- `boss_kino.webp` — Kino la Foudre
- `boss_sape.webp` — Sapé Moteur
- `boss_asphalte.webp` — Gaz na Gaz, le Baron de l'Asphalte
- `keyart_traversee.webp` — Keyart DLC paysage
